# 2025.11.15 Unscented Kalman filter (UKF)
## Introduction
### Kalman filterとは
- ノイズが含まれる観測データから、**予測と観測**を組み合わせて、システムの真の状態を推定する最適アルゴリズム
- 予測（予測ステップ）：->**odometry**
    - 対象物の動きに関して、直前の状態とシステムのダイナミクス（運動方程式など）に基づいて、次の状態を予測
- 観測（更新ステップ）：->**observation**
    - センサーなどで得られた不確実な観測値を考慮し、予測値を修正
- 推定：
    - 予測値と観測値の「重み付け平均」によって、その時点での最も信頼性の高い推定値（真値）を算出
- 繰り返し
    - 予測と更新のサイクルを繰り返し行うことで、刻々と変化するシステムの動的な状態を継続的に推定
### Extended Kalman Filterの課題
- ディジタル計算機の普及とともにKalman Filterの応用範囲は拡大
- BUT:Extended Kalman Filter(EKF)では、非線形性の高い系において十分な推定精度を得られなかった
- 具体的対象：
    - 極端な姿勢変化を伴う飛翔体やロボットのナビゲーション・姿勢推定
        - 特に、姿勢を表現する際にオイラー角などの特異点を持つパラメータ表現を用いた場合、大きな角度変化（例えば、航空機が宙返りするような動き）があると、**EKFの線形化の仮定が破綻**し、推定が不安定になったり、発散したり
    - Li-ionバッテリーの充電状態 (SOC: State of Charge) 推定
        - バッテリーの電気化学的な振る舞いは複雑な非線形特性を持っており、特に特定の動作条件下では非線形性が強くなる
        - EKFを用いてSOCを推定しようとすると、結果が発散してしまう
    - 急激な機動を行うターゲットの追跡
        - ターゲットが急激な方向転換や加減速を行う場合、その運動ダイナミクスが持つ非線形性が高くなり、EKFでは追従しきれずに推定誤差が大きくなる
- EKFの推定精度が不十分になる主な要因：
    - テイラー展開による1次近似
        - EKFは非線形なシステムモデルや観測モデルを、現在の推定値を中心とした1次テイラー展開によって線形システムとして近似
        - 非線形性が強い場合、この1次近似と実際の非線形関数の振る舞いとの乖離が大きくなる
    - ガウス分布の歪み
        - KFは、状態変数が常にガウス分布（正規分布）に従うと仮定
        - 非線形変換はガウス分布を一般に非ガウス分布（歪んだ分布）に変形させるが、EKFでは変換後の分布を強制的に再びガウス分布で近似
        - 非線形性が強いほど、この近似による情報損失が大
    - 共分散の過小評価と発散
        - 1次近似は、非線形関数の曲率（2階以上の微分項）を無視するため、推定される共分散（不確かさ）が過小評価されがち
        - 結果、フィルタゲインが不適切になり、最終的に推定が真の値から大きく外れて発散してしまうリスクが大きくなる
    - 初期値への依存性
        - EKFの性能は、初期状態推定値の精度に大きく左右される
        - 非線形性が高い系では、初期値が真の値から少し離れているだけで、線形化の有効な範囲から外れて収束しなくなることがある
- 上記のEKFの課題を解決するために開発されたのが、より高度な非線形フィルタリング手法である**Unscented Kalman Filter (UKF)**や**パーティクルフィルタ**

## Method: Unscented Kalman Filter (UKF)とは
### 開発背景
- UKFは1997年にSimon Julier氏によって発表
- Unscented (香りがない)はJulier氏によるもの
    - 全く新しく、既存の香りがついていない推定フィルタ
- KFの非線形性に関する課題の解決策は多く提案されていたものの、計算の複雑さや計算負荷が大きくなり、KFの良さであるシンプルさが失われていった
- UKFはEKFと考えが異なるものの、考え方そのものは比較的シンプルでわかりやすい
    - EKFと異なりヤコビアンを計算する必要がないため、計算アルゴリズムの実装はむしろ簡単になる
